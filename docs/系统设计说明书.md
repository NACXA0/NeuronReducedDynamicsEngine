# 第三部分：项目文档（系统设计说明书）
## 1. 系统架构总览
**FRE 采用两阶段架构：离线拟合（重计算、低频）与在线仿真（轻计算、高频）物理分离，通过序列化的“类型-激活函数”绑定表衔接。** 引擎主体不依赖 FlyGym，具身接口作为可选插件加载。整体参考 Norse 的“状态-计算分离”函数式风格；NumPy 为默认可移植后端，JAX 为可选 jit 加速。
文档版本：**v0.6（RFC-001）**。L0–L2 拟合产物；PySR 为可选精化器；EmbodiedEnv 抽象；α 以 Shiu 0.275 mV 为起点。

```
┌─────────────────────────────────────────────────────┐
│              离线阶段（fre.offline）                  │
│  Feather/CSV/Parquet ──► 解析器 ──► 稀疏图 + 类型表   │
│  类型表 + ODE 库 ──► L0 样条 / L1 LUT / L2 SRM；可选 PySR │
│                          │                            │
│                          ▼                            │
│         类型-激活函数绑定表（NPZ schema v2 + meta.json） │
└──────────────────────┬──────────────────────────────┘
                       │ 加载
┌──────────────────────▼──────────────────────────────┐
│              在线阶段（fre.engine）                   │
│  稀疏图 + 状态；混合模式：降阶 F + 指定子图 Euler ODE   │
│   速率 / 脉冲 LUT / SRM IIR                           │
└──────────────────────┬──────────────────────────────┘
                       │ EmbodiedEnv 插件
┌──────────────────────▼──────────────────────────────┐
│  FREFlyGymEnv | OpenLoopStimEnv（v0.1 不含自研身体）   │
└─────────────────────────────────────────────────────┘
```
v0.1 差异化不来自「能跑 MaleCNS」，而来自按类型绑定的降阶 F、相对原 ODE 的可报告误差、Shiu α 标定，以及可替换的具身接口。对外：「类型可绑定不同 F」。
## 2. 模块设计
### DD-1 连接组解析器（`fre.io.connectome`）
**输入** 突触表（**Feather 主路径**，Parquet/CSV 兼容），**输出** `GraphData` 数据类。数据结构：
```python
@dataclass
class GraphData:
    n_nodes: int
    node_ids: np.ndarray      # 原始 body id
    edge_index: np.ndarray    # (2, n_edges) int64  pre, post 重映射后下标
    edge_weight: np.ndarray   # (n_edges,) float32
    node_type: np.ndarray     # (n_nodes,) int32 索引到类型表
    type_names: tuple[str, ...]
    nt_type: np.ndarray | None
    region: np.ndarray | None
```
**关键决策**：权重初始化放在此模块（WBS-02.3），α 按（递质， pre_type）分组默认值表存于 YAML，允许用户覆盖；不在此模块做网络级标定，标定在 DD-6 处理。列名别名兼容 MaleCNS `body_pre`/`weight`/`consensus_nt` 与通用 `pre_id`/`synapse_count`。
### DD-2 单胞动力学库（`fre.models`）
**采用注册模式，每个模型实现统一接口 `rhs(t, y, I, params) -> dy/dt`、`y0(params)` 和 `reset(y, params)`。** 内置 LIF、ExpLIF、AdExpLIF、HH、Izhikevich；多房室留作 v0.2 扩展。单位约定：V [mV]、t [ms]、I [nA]、C [nF]、g [µS]（HH 采用等效点神经元换算）。模型参数以 `dataclass` 组织，允许从 YAML/JSON 声明式加载。
类型-模型映射表（`configs/type_model_map.yaml`）示例：
```yaml
- type_id: "default excitatory"
  model: "explif"
  params: {}
- type_id: "default inhibitory"
  model: "lif"
  params: { Vth: -48.0 }
- type_id: "hh_demo"
  model: "hh"
  params: {}
  ref: "Hodgkin-Huxley 1952 point-neuron scaling"
```
未匹配类型回退到 default 档（统一 LIF/ExpLIF）。literature 档 v0.1 目标：T4、aCC（AdExp 参数占位，待 ModelDB 精化）。禁止对外说「重建了 N 种真实动力学」。
### DD-3 离线拟合工具（`fre.offline`，RFC-001 全面重写）
**原则：离线可重，运行时必须轻。** 每类型经 FR-3.9 分配 L0–L2（L3/FNO 属 v0.2）。

| 层级 | 产物 | 捕获 | 运行时 | 拟合 |
|---|---|---|---|---|
| **L0** | 一维 r(I) | 稳态发放、增益/阈值 | O(1) | PCHIP / 分段多项式 |
| **L1** | 二维 F(I, Δt) | 状态依赖、基础适应 | O(1) | 二维 LUT |
| **L2** | SRM κ, η, θ 或 H(ω; I₀) | 共振、时序、适应 | O(1)/核（一阶 IIR） | 指数和 + 可选 PySR |
| **L3** | FNO / Volterra | 全瞬态 | FFT 级 | v0.2 |

- **L0**：电流网格扫描 + Euler；优先 PCHIP；Type-II / 去极化阻滞写入 `notes`，I < I_onset 强制 0 Hz。**禁止全局傅里叶基逼近 f-I**（rheobase Gibbs 振铃）。
- **L1**：`(I, Δt)` 一步响应 LUT（spike_mask, V_next）。AdExp 为 v0.1 主验证对象。
- **L2**：`fit_srm_kernels` 从脉冲响应拟合 κ/η/θ；运行时 `step_srm` 递归滤波。chirp `|Z(ω)|` 既是产物也是升层判据（有峰 → L2）。
- **PySR**：可选 `FitterBackend`（`pip install 'fre-neuron-engine[pysr]'`）。maxsize ≤ 20，维数 ≤ 2，样本 ≤ 10⁴，离线。准入考试失败则退场（`docs/pysr_admission.md`）。
- **序列化**：NPZ schema v2（`layer`, SRM 系数, `z_freqs`/`z_abs`, `pysr_expr`, `level_decision`）；加载器兼容 v1。

**拟合质量守门**：区间内 f-I R² ≥ 0.98（NFR-4）否则 `quality: "poor"`。
### DD-4 在线引擎（`fre.engine`）
**主循环为纯函数，状态外置。** 速率：`I_syn = W @ r`（gather-scatter），`r = F(I_syn + I_ext)`。脉冲：LUT 或 Izhikevich 2D。**局部回退**：`step_rate_mixed(..., fallback_types=...)` 对指定类型在线 Euler AdExp 级 ODE，同步点为 1 ms 步边界。失败回路写入 `docs/known-inapproximable.md`。F/LUT 边界外饱和并累加 `out_of_range`。
### DD-5 具身适配（`fre.adapters`）
```
EmbodiedEnv
 ├── sense_to_current(obs) -> I_ext
 ├── spikes_to_action(motor_out) -> action
 └── FREFlyGymEnv (FlyGym v2, v0.1)
     OpenLoopStimEnv (无身体，验证用, v0.1)
```
按 FlyGym v2 直接接口，**不按** Gymnasium `step(obs)`。引擎主体零 FlyGym 符号（NFR-8）。v0.1 **不含具身平台自研**；验收为接口 Demo（≥100 步无发散 + 感觉-运动统计相关），不构成行为主张。
### DD-6 校准与验证模块（`fre.calibration`, `fre.validation`）
- **单胞级**：`validate_single` — f-I MSE、R²、VP（q = 1/10 ms，窗口 1 s）；
- **回路级**：`validate_circuit` — 对照在线 Euler ODE；
- **系统级**：`validate_hopkins_flywire` — 仅 FlyWire 子集；禁止跨数据集映射神经元 ID；
- **α 标定**：`apply_shiu_weights` 使 \|w\| ≈ 0.275 mV × synapse_count 的电流等价；`calibrate_alpha` 在此起点上反推全局缩放，目标相对发放率误差 ≤10%。
## 3. 数据流与数据格式
**中间产物统一为 NPZ + JSON 元数据。** schema_version 现为 2，加载器兼容 1。`fitted_F.npz` 含：`I_grid, r_grid, layer, level_decision, lut_*, kappa_*/eta_*/theta_*, z_freqs, z_abs`；`meta.json` 含 `type_id` / `type_ids`、质量、`pysr_expr`、`fallback_ode`、`git_commit`、`config_hash`。M1 文件名可为模型键；M2 起迁类型键（见 `artifacts/README.md`）。MaleCNS 原始 Feather 不打进 wheel（`scripts/download_malecns.py` → `data/malecns/`）。
生物学失败写入 `docs/known-inapproximable.md`，不掩盖。

## 5. 测试与验证方案
单元测试覆盖：模型 rhs 与 LIF 解析解、拟合器 R² 守门、chirp/SRM/混合回退、引擎数值稳定性。集成测试：解析器-拟合器-引擎全链路、EmbodiedEnv 闭环（mock 或 `@pytest.mark.flygym`）。
## 6. 技术栈与版本锁定
| 组件 | 选型 | 版本策略 |
|---|---|---|
| 语言 | Python | ≥3.10 |
| 离线求解 | scipy.integrate, scipy.interpolate | 锁定 minor |
| 在线引擎 | NumPy 默认；JAX 可选 | 主选 JAX 加速，稀疏生态不足则保持 NumPy/PyTorch |
| 具身仿真 | FlyGym 2.x | 可选 extra；`EmbodiedEnv` 隔离 |
| 符号回归 | PySR | **可选 extra** `fre[pysr]`；主包无 Julia（NFR-11）；CI 独立 continue-on-error lane |
| 测试 | pytest + pytest-cov | 覆盖率 ≥70%；`-m "not pysr"` 为默认 |
| 文档 | MkDocs | — |
| CI | GitHub Actions（lint + test） | Python 3.11 |
## 7. 变更管理与版本策略
- 语义化版本：v0.x 允许接口破坏；拟合产物 schema 独立版本号，加载器兼容 n-1；
- 架构级变更走 RFC，写入 `docs/rfcs/`。
## 8. P0 最小可行原型
1. AdExp 离线 f-I + chirp |Z(ω)|，R² ≥ 0.98；LIF 作对照；
2. Shiu α 起点 + 100 节点两类速率闭环；
3. L1 LUT / L2 SRM、局部回退、EmbodiedEnv 100 步接口 Demo。
