# 意图与改进计划

决策正文是 [RFC-003](rfcs/RFC-003.md)。本页是给使用者看的摘要：引擎要干什么、现在缺什么、按什么顺序补。v0.1 验收数字仍以 [RFC-001](rfcs/RFC-001.md) 和 [证据链](reports/evidence.md) 为准；本页不改那些门槛。

## 终局

生物结构（连接组、类型、单胞动力学）是**教师来源**，不是产品终点。抽出的范式是：

\[
\Phi(r) = F_\tau\bigl(W(r\Delta t)+I_{\mathrm{ext}}\bigr)
\]

异质的局部 \(F_\tau\)、稀疏图上的混合、以及 L0/L1/L2 显式选择记多少记忆。引擎默认只开**类型**这一身份维，作为可嵌入的仿真基础设施（游戏、群落、控制同构：类型绑定局部映射，交互是图）。自定义维是开关，用来量哪一根轴对 \(\Phi\) 有贡献。终局是这一套最少数学能否形成智慧结构，并发展成新的 AI 基元——不是回答果蝇生理学问题。

未做到的事不写进 README 验收表。不说已形成智慧，也不说已得到新 AI。

## 三层用法（同一核）

| 层 | 谁用 | 默认合同 | 现状 |
|---|---|---|---|
| 仿真基础设施 | 游戏、群落、具身、开环刺激 | 图 + 类型表 + 步进；少维 | P1：CLI 按类型绑表；入门叙事仍是果蝇 |
| 范式探索 | 深度开发 | 加维是开关；关则与主线逐点相同 | `RateOp` 钩子有；还不是 \(F(I,\theta)\) 轴 |
| AI 基元 | 以后的结构搜索 / 学习 | 同一 \(\Phi\) 可当层；默认冻结 | v0.1 明确不做网络训练；需另开 RFC |

A1/A2 果蝇 Demo 仍是实例展示（[RFC-002](rfcs/RFC-002.md)），不是引擎定义。

主线身份维只有类型；脑区、坐标、调质默认恒等。速率主线用 L0；L1/L2 是记忆档，不是必须填写的生物 realism。自定义管道见 [extend](quickstart/extend.md)。

## 现在已经有的

- 离线拟合 L0/L1/L2，在线稀疏步进（`step_rate` / 脉冲 LUT / 局部 ODE 回退）
- 类型绑定表、npz schema、`ModelSpec` 换教师
- `EmbodiedEnv` 形状；FlyGym 为一个后端
- 发布集与证据链（逼近误差、墙钟、α）

## 计划

| 阶段 | 目标 | 交付 | 不做 |
|---|---|---|---|
| **P0** | 口径对齐 | RFC-003、本页、README / 文档地图 | 不改代码核、不改发布表 |
| **P1**（本轮） | 果蝇主叙事下的基础设施 | CLI `--fit` 回退 + `--fit-map`；JSON `bound`；`examples/06_swap_the_types.py` | 不新做游戏引擎；不增加默认身份维；不把 06 写进 README 安装块 |
| **P2** 范式探索 | 能量出「这根轴有没有用」 | 轴 vs `RateOp`；扰动/对比 \(\Phi\)；从拟合产物抽坐标；249 节点回路上一个反事实 | 不把自定义维写进发布主线 |
| **P3** AI 基元 | \(\Phi\) 可作层 | 可选可微封装；默认冻结。**另开 RFC** | 不改 NFR 证据；`simulate` 默认仍只读 |

P1 已决（原 RFC-003 Q12 / Q14）：单位仍按果蝇实例写 Hz / nA / ms，本轮不改核为无量纲；第一个非果蝇示例只换类型名，不进 A 层 Demo。入门仍是 `fetch fly` + `simulate --fit aCC_l0.npz`。换标签见 [稀疏传播](quickstart/engine.md) §4。


## 怎么读下去

1. 跑通 README 的安装 / 仿真 / 测试。
2. 把核当工具：[稀疏传播](quickstart/engine.md)。换教师或加维：[自定义管道](quickstart/extend.md)。
3. 冲突：禁止项以 RFC-001 为准；包与产品面以 RFC-002 为准；终局与改进顺序以 RFC-003 为准。
