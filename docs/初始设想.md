也有过于简单的只有神经元连接表格与激活函数的模拟https://github.com/ornata/fly

我想开发一个模拟引擎，只要神经元连接表格，但是要通过解算神经元单细泡动力学为近似的激活函数，在计算时作为影响参数，实现高效的近似。

对各个神经元的高仿真结果进行多维度的函数拟合，实现更快速度且保真度相对于全脑使用一个LIR函数更高。
科学才只讨论现实；工程需要适当的抽象才能发展与进化。
适当的抽象神经元行为为多维度的你和函数，更容易发现规律找到扩展神经元体积的方法。

下面是初步设计：
# 方案总览
我的定位：
> 输入：**神经元连接表（邻接矩阵/突触列表）**
> 内核：**单神经元动力学ODE，预计算/拟合成近似激活函数**，绑定到每一类神经元
> 目标：轻量脉冲网络引擎，不用在仿真循环里实时求解微分方程；能对接FlyGym做具身闭环

一句话概括思路：
**离线求解每类神经元的动力学方程，把「膜电位→发放率/spike」映射拟合为一个可快速求值的激活函数；仿真主循环只做图传播 + 调用这个激活函数，不再每步解ODE。**

> 本质：把神经元动力学从**在线微分求解** → 转为**查表/解析近似函数**。
> 区别于原生LIF：LIF本身已经是极简分段函数；支持更真实的单胞模型（HH、多房室），但用近似函数替换掉实时ODE。

## 一、核心概念拆分
### 1. 神经元单胞动力学（离线阶段）
对于一类神经元（比如感光细胞、中央复合体、运动神经元），给定模型（LIF / ExpLIF / HH）：
$$
C_m \frac{dV}{dt} = I_{in}(t) - g_L(V-E_L) + \text{离子通道电流}
$$
传统做法：仿真循环每一步，数值积分（欧拉/Runge-Kutta）更新V。

我的思路：
1. **离线采样参数空间**：扫描输入电流 $I_{in}$、历史状态（上次膜电位、上次spike时间、不应期）；
2. 运行ODE求解器，得到稳态发放率 $r$ / 下次spike时刻；
3. 拟合一个近似函数 $r = F(I_{in},\text{state})$，可以是：
   - 解析函数（sigmoid、分段多项式）
   - 样条插值
   - 查找表(LUT)
4. 保存这个函数**绑定到该神经元类型**。

> 仿真运行时：不再解ODE，直接调用 $F$，输入总突触电流，输出发放率/是否产生spike。

✅ 优势：
- 仿真主循环极快，适合几十万神经元（MaleCNS级别），可以GPU向量化；
- 仍然保留**不同细胞类型的差异化动力学特征**，而不是全部神经元共用同一个LIF公式；
- 只需要连接表 + 每个神经元的细胞类型（连接组里自带细胞类型标注）。

⚠️ 代价：
- 是**状态压缩近似**。如果神经元动态有长时记忆、复杂瞬态，近似会丢失部分精细行为；
- 离线预计算要覆盖足够参数范围，否则仿真时遇到超出采样区间会失效；
- 只适合**单胞动力学**，**突触动力学（STP、可塑性）如果是非线性，也要额外做近似**。
