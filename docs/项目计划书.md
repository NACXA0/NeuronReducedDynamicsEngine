# 第二部分：项目计划书
文档版本：**v1.1（RFC-001）**。对照对象：Shiu et al. *Nature* 2024 为 **FlyWire 成体脑** LIF，`W_syn=0.275 mV` 为 α 默认起点。不得与 MaleCNS ID 混用。

## 1. 项目目标
**在 6 个月内交付 v0.1：连接组驱动、按类型绑定降阶 F（L0–L2）、α 以 Shiu `W_syn=0.275 mV` 为起点、可对接 FlyGym v2 接口 Demo 的引擎。** 不追求方法级原创，定位为 SRM/AdExp/MAT 谱系的系统级集成。
## 2. 范围与边界
**纳入范围**：Feather 连接组解析、单胞库（LIF 对照 / AdExp 主对象 / HH）、L0–L2 离线拟合（样条、LUT、SRM IIR、可选 PySR）、速率与脉冲、α 标定、EmbodiedEnv + FlyGym 接口 Demo、局部 ODE 回退。
**排除范围（v0.1 明确不做）**：STP/STDP、多房室、网络级训练、电导型突触、CUDA 内核、FlyBrainLab 功能对标、L3/FNO、具身平台自研。
## 3. 里程碑计划
| 里程碑 | 交付物（RFC-001） | 验收口径 | 工期 |
|---|---|---|---|
| **M0** | 需求 v1.1 + 架构 v0.6（并入 RFC-001） | FR↔DD↔TC 可追溯 | 第 1–2 周 |
| **M1** | AdExp 离线拟合 + ODE vs F + chirp \|Z(ω)\| + PySR 准入考试 | FR-3.1/3.6–3.9、NFR-4 | 第 3–5 周 |
| **M2** | 速率引擎 10k + α 标定（Shiu 起点并反推） | FR-4.1、FR-1.5、NFR-1；标定相对误差 ≤10% | 第 6–10 周 |
| **M3** | L1 LUT + L2 SRM IIR + 局部回退 + 回路对照 | FR-3.8、FR-4.2、NFR-5/12 | 第 11–16 周 |
| **M4** | EmbodiedEnv + FlyGym 接口 Demo | FR-5；≥100 步无发散 + 统计相关 | 第 17–19 周 |

**v0.2（新增）**：FNO 分支（AdExp 上与 L2 比精度/速度）、HH 入网、电导型突触、SimpleKinematicsEnv。

## 5. 团队与角色（个人开发者配置）
- **架构师/开发者**（本人）：全栈实现、需求与设计文档；
- **顾问（远程）**：神经科学顾问（建议寻找 1-2 位，主要在细胞类型电生理参数、回路选择、结果解读上把关）；
- **社区**：GitHub Issues 作为用户反馈渠道，目标 v0.1 后引入首位外部贡献者。

## 7. 验收与交付
- 每个里程碑完成时更新 `CHANGELOG.md` 并打 Git tag；
- v0.1 交付物：PyPI 包（或 Wheel）、文档站点（Sphinx/MkDocs）、3 个可运行示例（单胞拟合、回路仿真、FlyGym 闭环）；
- 验收以第一部分 §6 为准。
## 8. 治理与流程
- **变更管理**：需求变更须走 RFC（30 行以内的轻量提案）+ 更新需求文档版本；
- **代码评审**：个人开发者采用“自评 + 顾问抽查”模式，所有 PR 附测试；
- **文档纪律**：需求-设计-测试三者双向可追溯（在需求文档中每条 FR 下列出对应设计条目 DD-x 和测试用例 TC-x）；
- **工具链**：Git + GitHub Actions，Python ≥3.10（CI 3.11），`ruff` + `pytest`。
