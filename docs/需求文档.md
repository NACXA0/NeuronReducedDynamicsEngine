# 第一部分：需求文档（软件需求规格说明书）
## 1. 引言
**本文档定义 NRDE v0.1 的软件需求，覆盖功能性需求、非功能性需求、外部接口与验收标准。** NRDE 的产品定位是：输入连接组表格（邻接列表 + 细胞类型标注），内核为按细胞类型预拟合的单胞动力学近似激活函数，输出可对接 FlyGym v2 的具身闭环脉冲/速率信号。
术语定义：**连接表** 指 FlyWire/MaleCNS 提供的突触列表（pre_id, post_id, synapse_count, 递质类型）；**降阶激活函数** 指离线求解单胞 ODE 后拟合的 F(I, state) 映射；**单胞动力学** 指 LIF/ExpLIF/HH/多房室等电生理模型。
文档版本：**v1.1（RFC-001）**。
## 2. 总体描述
### 2.1 用户画像
- **主用户**（项目开发者）：神经计算/具身智能研究者，需要全脑规模、可对接 FlyGym 的因果仿真环境；
- **次用户**：使用 NRDE 作为黑箱环境的 RL/控制算法开发者；
- **远期用户**：果蝇神经科学工作者，用于生成可实验验证的回路假设。
### 2.2 运行环境与约束
- **离线拟合阶段**：Python 3.10+，`scipy.integrate.solve_ivp` + `scipy.interpolate`，普通工作站即可；
- **在线仿真阶段**：NumPy 为默认可移植后端；JAX（首选加速，因 Norse 的函数式状态-计算分离设计更贴近 JAX）或 PyTorch 为可选。单 GPU（≥12GB 显存）应可承载 MaleCNS 规模的稀疏传播；无 GPU 时允许 CPU 回退；
- **数据边界**：MaleCNS 全中枢神经系统包含 166,691 个神经元、11,691 种细胞类型；FlyWire 脑级约 14 万神经元、>5000 万突触；
- **物理时基**：仿真步长固定 1 ms，与 FlyGym 物理步长对齐；
- **外部接口**：FlyGym 2.x.x 已放弃 Gymnasium 合规，改为直接仿真接口（`get_*` / `set_actuator_inputs` / `sim.step`），CPU 性能较 1.x 提升 10 倍，NRDE 适配 v2 API。
### 2.3 假设与依赖
- 连接表中递质类型标注可用（FlyWire Codex / MaleCNS neurotransmitter Feather 提供）；
- 突触电导与突触计数之间采用线性映射 w = α(递质类型, pre 细胞类型) × synapse_count，α 为网络级标定参数；
- 细胞类型的电生理参数在 v0.1 阶段允许默认值（LIF 家族），但拟合流水线与类型表必须额外绑定至少一种非 LIF（AdExp 或标准 HH）；v0.2 起从文献/ModelDB 大规模引入。对外表述为「类型可绑定不同 F」，不宣称已重建全部 1 万种真实动力学。
### 2.4 数据源清单（RFC-001 D12）
| 管线 | 数据源 | 服务模块 | 对拟合 F 的作用 |
|---|---|---|---|
| 连接组侧 | MaleCNS Feather、FlyWire | DD-1 图结构、FR-1.5 权重、DD-6 α 标定 | 无（不产生 f-I） |
| 电生理侧 | ModelDB、NeuroElectro、文献单类记录 | DD-2 参数、DD-3 拟合原料 | 直接决定 F 质量 |
引入更多连接组的价值是更多可标定回路，**不**增加 f-I 曲线数量。
## 3. 功能性需求
### FR-1 连接组解析
对应设计 **DD-1**，测试 **TC-1.x**（`tests/test_connectome.py`）。
- **FR-1.1** 支持 MaleCNS/FlyWire 导出的突触表。**MaleCNS 主格式为 Apache Arrow Feather**（`connectome-weights-*.feather`、`body-annotations-*.feather`、`body-neurotransmitters-*.feather`）；CSV/Parquet 为可选导出兼容。字段至少含 pre_id, post_id, synapse_count, nt_type（递质）；加载器识别常见列名别名；
- **FR-1.2** 按细胞类型对节点分组，生成 `type → F(·)` 绑定表；
- **FR-1.3** 构建稀疏邻接矩阵（COO/CSR），支持 GPU 上的稀疏矩阵乘（`jax.experimental.sparse` 或 torch.sparse）；无加速库时使用 gather-scatter；
- **FR-1.4** 允许子网裁剪（按脑区/细胞类型子集构建子网络）；
- **FR-1.5** 权重初始化：w = α × synapse_count；默认 α 取 Shiu `W_syn = 0.275 mV` 的电流等价（`SHIU_ALPHA_NA`），允许 (nt_type, pre_type) 覆盖。标定绑定 M2。
### FR-2 单胞动力学库
对应设计 **DD-2**，测试 **TC-2.x**（`tests/test_models.py`）。
- **FR-2.1** 内置模型按降阶收益标注：LIF/ExpLIF（对照，`reduction_benefit=control`）、AdExp（v0.1 验证主对象）、HH（v0.2）、Izhikevich（L2 应急）。拟合验证对象强制含 AdExp 慢变量；
- **FR-2.2** 类型表分三档：`default` / `literature`（v0.1 目标 T4、aCC）/ `reserved`。对外只说「类型可绑定不同 F」；
- **FR-2.3** 库采用注册机制，新增模型只需实现 `rhs(t, y, I)`、`y0` 和 `reset` 接口。
### FR-3 离线拟合 Pipeline
对应设计 **DD-3**，测试 **TC-3.x**（`tests/test_fit.py`）。
- **FR-3.1** 对给定类型扫描输入电流 I ∈ [I_min, I_max]（用户可配，默认覆盖静息至 200 Hz 饱和段），用 `solve_ivp` 或固定步长 Euler 求解至稳态，提取 f-I 曲线（路线A）；
- **FR-3.2** 路线B：对状态空间 (I, t_since_last_spike) 网格采样，求解一步响应，生成二维 LUT；
- **FR-3.3** 拟合产物序列化（NPZ + JSON 元数据），格式含类型 ID、拟合方法、采样范围、验证误差、schema 版本；
- **FR-3.4** 拟合过程可并行（多类型 × 多电流批）；
- **FR-3.5** 超出采样区间的输入触发安全外插（饱和）并记录告警（`out_of_range` 计数）；
- **FR-3.6** 频域 chirp：输出阻抗谱 |Z(ω)|，有峰则升 L2（RFC-001）；AdExp 为 M1 主验证对象；
- **FR-3.7** PySR 后端为可选 `FitterBackend`（`nrde[pysr]`），导出表达式字符串；主包不引入 Julia；准入考试失败则退场；
- **FR-3.8** SRM 核 κ/η/θ 以指数和表示，运行时一阶 IIR（NFR-12）；
- **FR-3.9** 拟合后自动分配 L0/L1/L2（L3/FNO 属 v0.2）。
### FR-4 仿真主循环
对应设计 **DD-4**，测试 **TC-4.x**（`tests/test_engine.py`）。
- **FR-4.1** 速率模式（路线A）：每步执行 `r = F(I_total)`，I_total = W · r_prev + I_ext（约定 W 按 post←pre 聚合）；
- **FR-4.2** 脉冲模式（路线B）：维护 V 和 t_since_spike 状态张量，查表决定是否发放，发放后沿稀疏图传播电流脉冲；LUT 质量不足时允许局部切 Izhikevich/AdExp 显式 2D 更新；
- **FR-4.3** 不应期与绝对不应处理（查表实现）；
- **FR-4.4** 感觉神经元输入通道：预留接口允许外部注入电流（对应视觉/嗅觉/机械感受等）；
- **FR-4.5** 运动输出解码：指定一组 VNC 运动神经元，将其发放（速率或 spike 计数）转换为 FlyGym 动作信号；
- **FR-4.6** 主循环为纯函数，状态外置；JAX 可用时需 jit 可编译，状态通过 `jax.lax.scan` 或显式传参管理。
### FR-5 FlyGym 适配器
对应设计 **DD-5**，测试 **TC-5.x**（`tests/test_flygym.py`，`@pytest.mark.flygym` 可选）。
- **FR-5.1** 实现 `sense → inject`：将 FlyGym v2 观察中的视觉像素/嗅觉强度编码为对应感觉神经元的注入电流（支持简单的线性/查表编码器）；
- **FR-5.2** 实现 `motor → action`：将运动神经元发放解码为关节或 CPG 级动作向量（v0.1 允许简单的低通滤波/阈值编码）；
- **FR-5.3** `EmbodiedEnv` 抽象基类；`NRDEFlyGymEnv` 为 FlyGym v2 实现，另有 `OpenLoopStimEnv`。v0.1 不含具身平台自研。接口 Demo：≥100 步无发散、感觉-运动统计相关可复现，不要求方向性/适应性。
### FR-6 校准与验证工具
对应设计 **DD-6**，测试 **TC-6.x**（`tests/test_validation.py`、`tests/test_calibration.py`）。
- **FR-6.1** 单胞级验证：对比拟合 F 与原 ODE 在同一电流序列下的发放序列，输出 Victor-Purpura 距离和 f-I 曲线 MSE；
- **FR-6.2** 回路级验证：对选定子网，对比降阶引擎与在线 ODE（自写 Euler；Brian2 为可选交叉实现）的下游响应；
- **FR-6.3** 网络级对照：与 Shiu et al. / Johns Hopkins 全脑统一 LIF 模型在相同感觉输入下的行为输出对比。**对照必须使用 FlyWire 成体脑子集**（该模型的原生数据集），禁止与 MaleCNS 神经元 ID 混用。MaleCNS 全图仅作为加载与速率一步的性能/规模测试（NFR-3）。
## 4. 非功能性需求
| 编号 | 类别 | 指标 |
|---|---|---|
| NFR-1 | 性能 | 10k 神经元速率模式，单 GPU，≥10× 实时（1 s 墙钟 ≥ 10 s 物理时间）。CPU 回退时以正确性与不发散为验收，性能作报告 |
| NFR-2 | 性能 | 1 万脉冲模式，≥1× 实时（GPU）；CPU 回退同上 |
| NFR-3 | 规模 | 支持全 MaleCNS（166k 神经元）速率模式加载与运行（允许显存降级为 CPU） |
| NFR-4 | 精度 | 单胞 f-I 拟合 R² ≥ 0.98 在采样区间内 |
| NFR-5 | 精度 | 脉冲模式：在 **1 s 比较窗口**内，Victor-Purpura 距离（cost **q = 1/10 ms = 100 s⁻¹**）相对全插入/删除距离 `(n_ref + n_approx)` 的中位数 ≤ 10% |
| NFR-6 | 可扩展性 | 新增细胞类型无需改动引擎代码，仅需在类型-模型表中追加条目 |
| NFR-7 | 可维护性 | 离线拟合与在线引擎代码物理分离（不同包/子模块） |
| NFR-8 | 可移植性 | 核心引擎不依赖 FlyGym，FlyGym 适配作为可选插件 |
| NFR-9 | 可复现性 | 所有实验可通过单一配置文件（YAML/TOML）+ 固定随机种子复现 |
| NFR-10 | 数据 | 每类型可用电生理源数量作为 F 拟合瓶颈，季度跟踪 |
| NFR-11 | 安装 | PySR 为可选依赖；`pip install neuron-reduced-dynamics-engine` 不得因 Julia 失败 |
| NFR-12 | 性能 | L2 SRM 每步 O(1)/核，不高于二维 LUT 求值的 3 倍 |
## 5. 外部接口
- **IF-1** MaleCNS/FlyWire 连接表数据接口（Feather 主路径，CSV/Parquet 兼容）；
- **IF-2** FlyGym v2 API：`get_raw_vision` 及其他 `get_*`、`set_actuator_inputs`、`sim.step`；**不使用** Gymnasium `env.step(obs)`；
- **IF-3** 可选：Brian2 交叉验证接口；
- **IF-4** CLI 与 Python API 双入口。
## 6. 验收标准（v0.1 / RFC-001）
1. AdExp（含慢变量）单胞：拟合 F 与在线 ODE 的 f-I 达 NFR-4，且可生成 chirp |Z(ω)| 报告（无论有无峰）；
2. 脉冲模式：L1 LUT 或 L2 SRM 在测试子网上与在线 ODE 的 VP 距离满足 NFR-5；
3. **接口 Demo**：EmbodiedEnv + FlyGym 后端 ≥100 步闭环，无发散、无 NaN，感觉输入与运动输出统计相关可复现（不要求方向性/适应性，不构成行为主张）；
4. **α 标定**：Shiu `W_syn=0.275 mV` 为起点；相对目标发放率误差工具本身可计算（回路级 ≤10% 为标定验收口径）；
5. FR-1 至 FR-6 的 v0.1 条目测试通过，覆盖率 ≥70%；PySR 准入考试通过或明确记录退场。
