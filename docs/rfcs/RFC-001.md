# RFC-001 NRDE 改进意见（v0.1 计划基线更新）

**文档编号**：RFC-001  
**状态**：已采纳（v0.1 计划基线）  
**日期**：2026-09-18  
**前序**：需求规格 v1.0、项目计划书 v1.0、系统设计说明书 v0.5  
**变更性质**：范围收缩、优先级重排、架构升级（不影响核心可行性结论）  
**追溯**：原 FR / NFR / DD / M / R 编号不变，内容以本文为准。

## 0. 决策摘要

1. **v0.1 成败关键是突触权重标定（α / W_syn），不是激活函数形式。** Shiu 等人 FlyWire 全脑模型：单一 `W_syn = 0.275 mV` + 统一 LIF ≈ 91% 下游发放预测。标定前移至 **M2**。
2. **离线拟合对 LIF 几乎无降阶收益。** M1 验证对象强制为 **AdExp（含慢变量 w）**；LIF 仅作对照。
3. **“多个拟合函数”的正确形态是 SRM 核族 / 频域传递函数族**，不是一堆无关的 f-I。运行时保持 O(1)/核。
4. **预计算算力不受限，运行时必须轻。** PySR、FNO 只做离线可选层。
5. **PySR** 是 L0/L1/L2 的可选精化器，不是默认路径；主包安装不得引入 Julia（NFR-11）。准入考试失败则整条退场。
6. FlyGym 下沉为 `EmbodiedEnv` 的一个后端；v0.1 只验收接口 Demo。
7. 对外只说「类型可绑定不同 F」，禁止「重建了 N 种真实动力学」。

## 2. 四层拟合产物（DD-3）

| 层级 | 产物 | 运行时 | v0.1 |
|---|---|---|---|
| L0 | 一维 r(I) | O(1) 查表 | 全类型默认 |
| L1 | 二维 F(I, Δt) | O(1) 查表 | literature 档 |
| L2 | SRM κ, η, θ 或 H(ω; I₀) | O(1)/核（IIR） | \|Z\| 有峰或 VP 超阈 |
| L3 | FNO / 二阶 Volterra | FFT 级 | **移出 v0.1** |

**PySR 定位**：L0/L1/L2 的可选精化器（maxsize ≤ 20，样本 ≤ 10⁴，维数 ≤ 2，离线）。不做默认路径、不做 >3 维、不做在线训练。准入考试：64 点 LIF 闭式 f-I，30 分钟，结构含 log/有理式。不通过则退场。

禁止用全局正弦/傅里叶基直接逼近 f-I（rheobase Gibbs 振铃）。

## 4. 验收（v0.1）

1. AdExp 单胞 f-I 达 NFR-4，且可生成 chirp \|Z(ω)\| 报告。
2. L1 或 L2 与在线 ODE 的 VP 距离达 NFR-5。
3. EmbodiedEnv + FlyGym ≥100 步闭环，无发散/NaN，感觉-运动统计相关可复现（不构成行为主张）。
4. α 标定以 Shiu 为起点；回路级相对误差 ≤10%。
5. FR v0.1 测试通过，覆盖率 ≥70%；PySR 通过或记录退场。

## 5. 宣传口径

允许：「类型可绑定不同 F」「具身接口基础设施」「FlyWire∩MaleCNS 重叠回路对照」「降阶方法的系统级集成」。  
禁止：「重建了 N 种真实动力学」「虚拟果蝇产生有意义行为」「跨数据集 ID 混用」「方法级原创（不引用 SRM/AdExp/MAT）」。

必须引用：Shiu et al. 2024；Jolivet/Gerstner SRM；Brette & Gerstner 2005；Kobayashi 2009 MAT；Di Volo 2019 / Becker 2024；FlyBrainLab；Neurokernel；PySR (Cranmer)。
