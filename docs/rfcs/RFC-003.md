## 0. 决策摘要

v0.1 已经把引擎做成两阶段计算核：离线把教师动力学压成类型绑定的 \(F\)，在线只做

\[
I = W\,(r\,\Delta t)+I_{\mathrm{ext}},\qquad r = F(I).
\]

此前文档把成功标准停在逼近误差、墙钟和果蝇实例。缺的一层是：**生物是这个数学范式的来源，不是终点。** 引擎要能当基础设施嵌入游戏、群落等图动态；自定义维用来量各轴对 \(\Phi=F\circ W\) 的贡献；终局是从该范式形成可复用的智慧结构，并由此发展新的 AI，而不是回答生物学问题清单。

| # | 决定 | 影响 |
|---|---|---|
| D24 | 终局：范式 → 智慧结构 → 新 AI；生物为来源 | README / 路线图；宣传仍守 RFC-001 |
| D25 | 默认唯一身份维是类型；内核无领域 | B 层合同；FlyGym / Shiu 单位属实例 |
| D26 | 工具少维、探索加维，二者不冲突 | `RateOp` / 自定义管道 |
| D27 | 当前管道是钩子，不是 \(F\) 的轴系统 | 禁止把乘性滤镜说成新自变量 |
| D28 | RFC-001 禁止项与「v0.1 不做网络训练」仍有效 | 可学习 \(\Phi\) 另开 RFC |
| D29 | 探索优先：类型粒度、L0/L1/L2、\(W\)、IO | 身份轴默认关 |
| D30 | 改进分 P0–P3；本轮只做 P0（文档） | [路线图](../roadmap.md) |

## 1. 终局（D24）

从连接组这类生物结构抽出的建模范式是：

1. **异质局部映射**：类型 \(\tau\) 共享 \(F_\tau\)，不是全图一个非线性。
2. **在线不积教师 ODE**：局部动力学被编译成可快速求值的 \(F\)（L0 无记忆；L1/L2 把记忆留在状态轴）。
3. **混合只发生在稀疏图上**：能力若出现，来自 \(\Phi(r)=F(W(r\Delta t)+I_{\mathrm{ext}})\)，不是单胞公式变长。
4. **\(F\) 的教师可以不是 ODE**：自定义管道允许与生物无关的映射，用来试抽象规则。

终局问题是：这一套最少数学是否足以形成智慧结构，并作为新 AI 的基元。果蝇 MaleCNS、AdExp 教师、Shiu \(\alpha\) 是规模、保真和标定的**实例**，用来约束范式，不是产品目的。

允许说：「类型可绑定不同 \(F\)」「同一核可嵌入非神经图动态」「自定义维用于消融 \(\Phi\)」。  
禁止把终局说成：「已形成智慧」「已得到新 AI」「已解释大脑」。未做的能力写进路线图，不写进验收表。

## 2. 引擎工具合同（D25）

B 层内核只保证：

- 图 \(W\)（节点、有向边、权重、类型索引）
- 资产 `type_id → F`（默认 L0；记忆可选 L1/L2）
- 纯函数步进 `state, I_ext → state'`（状态外置）

领域把观察写成 \(I_{\mathrm{ext}}\)、把读出写成动作。`EmbodiedEnv` 是适配器形状；FlyGym 是其中一个后端。游戏 tick、群落交互图、开环刺激，只要满足上列三项即可接入。

毫秒、纳安、\(W_{\mathrm{syn}}=0.275\,\mathrm{mV}\) 属于果蝇预设，不是内核必填。v0.1 实现仍用这套单位跑发布集；无量纲步进是 P1，不在本轮改代码。

A 层仍是果蝇 Demo / 预设（RFC-002 A1/A2）。B 层文档与 API 不得把「会跑 MaleCNS」写成引擎定义。

## 3. 少维默认，加维探索（D26、D27、D29）

工具属性与科学属性共用一个核：默认合同只有类型这一身份维；其余维是开关。未打开时必须与发布主线逐点相同。

| 轴 | 默认 | 角色 |
|---|---|---|
| 类型 \(\tau\) | 开 | 唯一默认身份维；异质性的粒度 |
| 状态 L0/L1/L2 | 速率主线 L0 | 记忆维；对 \(\Phi\) 的贡献优先于身份轴 |
| 图 \(W\) | 开 | 混合；不是 \(F\) 的维 |
| IO 绑定 | 适配器 | 没有 IO，\(\Phi\) 只是场内迭代 |
| 脑区 / 坐标 / 调质 | 关（恒等） | 自定义维；用来证明关掉无影响 |

当前 `RateOp`（`type → place → modulator → 用户步`）是发放率后处理钩子。`r *= g(\mathrm{region},\mathrm{xyz})` **不是**给 \(F\) 增加自变量。真轴形态是 \(F(I,\theta)\) 或对 \(F\) 坐标做 swap / morph / ablate。把未注册、无教师的映射写入 `datasets/fly/` 或标 `quality=ok` 仍禁止（RFC-001）。

探索的对象是范式，不是果蝇生理学问题清单。自定义维的合法问题形如：关掉记忆层后 \(\Phi\) 还能否维持某通路增益；把两类 \(F\) 合成一类后图动态差多少。

## 4. 与 v0.1 的关系（D28）

RFC-001 的分层、α 标定、宣传禁止项、NFR 数字全部保留。RFC-002 的三产品面、单向洋葱、历史规格不改写（D23）全部保留。

v0.1 **仍不做**：STP/STDP、多房室、电导型突触、网络级训练、L3/FNO、具身平台自研。Torch 路径仍是更快的 SpMV，不是可训练模块。

可学习的 \(\Phi\)（把同一 \(F,W\) 暴露成层、训练 \(W\) 和/或 \(F\) 的坐标）是终局所需要的第三面。它与只读仿真不冲突（默认冻结），但会碰到「v0.1 不做网络训练」。因此 **P3 必须另开 RFC**，不得借本文件把训练塞进 v0.1 验收。

## 5. 改进计划（D30）

用户可读摘要在 [意图与改进计划](../roadmap.md)。代码增量按阶段另开 PR；本 RFC 采纳不等于实现 P1–P3。阶段号属于本文，与 RFC-002 §6 的仓库治理清单不是同一套。

| 阶段 | 目标 | 做 | 明确不做 |
|---|---|---|---|
| **P0** 文档 | 口径对齐终局 | 本文件；路线图；README / 文档地图 / 自定义管道 | 不改步进核、不改发布 npz |
| **P1** 基础设施 | B 层可当无领域中间件 | 按类型绑定表（CLI 不再一张 fit 铺全图）；无领域示例；适配器与果蝇单位解耦（文档+最小代码） | 不新做游戏引擎；不加默认身份维 |
| **P2** 范式探索 | 自定义维能量 \(\Phi\) | 区分轴与 `RateOp`；扰动/对比 \(\Phi\)；从 L0/L1/L2 抽坐标；附属屈肌回路上一个反事实 | 不把身份轴写进发布主线；不宣称生物学结论 |
| **P3** AI 基元 | 同一 \(\Phi\) 可作层 | 可选可微封装；默认冻结；训练 \(W\) 或 \(F\) 坐标走新 RFC | 不改 NFR 证据链；不把训练做成默认 `simulate` |

P1 的验收口径：不读果蝇文档也能用 `GraphData` + `FittedActivation` + `step_rate` 跑通一个非神经类型图示例。  
P2 的验收口径：同一张图上两套 \(F\) 绑定可对比，且默认管道与自定义全关时逐点相同。  
P3 的验收口径：另开 RFC 后才定；在此之前文档只写「预留」。
